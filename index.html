№2 Метод математической индукции (ММИ)[span_12](start_span)[span_12](end_span)

Пусть \(P(n)\) - предикат, где \(n \in \mathbb{N}\)[span_13](start_span)[span_13](end_span). Если истинны: (1) база \(P(1)\) и (2) переход \(P(k) \implies P(k+1)\), то \(\forall n \in \mathbb{N} P(n)\) истинно[span_14](start_span)[span_14](end_span).

Неравенство Бернулли: \(\forall n \in \mathbb{N}, \forall x \ge -1: (1+x)^n \ge 1+nx\)[span_15](start_span)[span_15](end_span).

Доказательство по ПМИ[span_16](start_span)[span_16](end_span):

  • База: При \(n=1\), \(\forall x \ge -1: (1+x)^1 \ge 1+1\cdot x\) - верно[span_17](start_span)[span_17](end_span).
  • Переход: Предположим, что \(P(k)\) истинно, то есть \((1+x)^k \ge 1+kx\)[span_18](start_span)[span_18](end_span). Хотим доказать \(P(k+1)\): \((1+x)^{k+1} \ge 1+(k+1)x\)[span_19](start_span)[span_19](end_span).
  • \((1+x)^{k+1} = (1+x)^k \cdot (1+x) \ge (1+kx)(1+x) = 1+(k+1)x+kx^2\)[span_20](start_span)[span_20](end_span).
  • Поскольку \(kx^2 \ge 0\), получаем \((1+x)^{k+1} \ge 1+(k+1)x\). Переход верен[span_21](start_span)[span_21](end_span).

№3 и №4 Перестановки, размещения и сочетания[span_22](start_span)[span_22](end_span)[span_23](start_span)[span_23](end_span)

Правило произведения: если первый объект выбирается \(m\) способами, а после этого второй \(k\) способами, то пару можно выбрать \(m \cdot k\) способами[span_24](start_span)[span_24](end_span).

  • Перестановка - упорядоченный набор из \(n\) различных элементов[span_25](start_span)[span_25](end_span). Формула: \(P_n = n(n-1)\dots 2 \cdot 1 = n!\)[span_26](start_span)[span_26](end_span).
  • Размещение из \(n\) по \(k\) (\(k \le n\)) - упорядоченный набор \(k\) различных элементов из \(n\)-элементного множества[span_27](start_span)[span_27](end_span). Формула: \(A_n^k = \frac{n!}{(n-k)!}\)[span_28](start_span)[span_28](end_span).
  • Сочетание из \(n\) по \(k\) - неупорядоченный выбор \(k\) элементов (\(k\)-элементное подмножество)[span_29](start_span)[span_29](end_span). Формула: \(C_n^k = \frac{A_n^k}{k!} = \frac{n!}{k!(n-k)!}\)[span_30](start_span)[span_30](end_span).

Полезные свойства[span_31](start_span)[span_31](end_span):

  • \(C_n^k = C_n^{n-k}\)[span_32](start_span)[span_32](end_span).
  • \(C_n^k + C_n^{k-1} = C_{n+1}^k\) (правило Паскаля)[span_33](start_span)[span_33](end_span).
Бином Ньютона: \((a+b)^n = \sum_{k=0}^n C_n^k a^k b^{n-k}\)[span_34](start_span)[span_34](end_span).

Доказательство (в общем виде): \((a+b)^n = (a+b)(a+b)\dots(a+b) = a^n + C_n^1 a^{n-1}b + \dots + C_n^k a^{n-k}b^k + \dots + C_n^n b^n\)[span_35](start_span)[span_35](end_span).

Замечание: \(C_n^n = C_n^0 = 1\), так как \(0! = 1\)[span_36](start_span)[span_36](end_span).

№4 Понятие последовательности и предела[span_37](start_span)[span_37](end_span)[span_38](start_span)[span_38](end_span)

Последовательность - набор вещественных чисел, пронумерованный натуральными индексами[span_39](start_span)[span_39](end_span).

\(\varepsilon\)-окрестность точки \(a \in \mathbb{R}\) при \(\varepsilon > 0\): \(U_\varepsilon(a) = (a-\varepsilon, a+\varepsilon)\)[span_40](start_span)[span_40](end_span).

Предел последовательности: \(a\) - предел последовательности \((a_n)\), если \(\forall \varepsilon > 0 \exists N=N(\varepsilon) \forall n > N : |a_n - a| < \varepsilon\)[span_41](start_span)[span_41](end_span).

Это равносильно \(a-\varepsilon < a_n < a+\varepsilon\)[span_42](start_span)[span_42](end_span).

Единственность предела: Сходящаяся последовательность имеет только один предел[span_43](start_span)[span_43](end_span).

Доказательство: Пусть \(a_n \to a\) и \(a_n \to b\)[span_44](start_span)[span_44](end_span). Возьмем \(\varepsilon = \frac{|a-b|}{3} > 0\)[span_45](start_span)[span_45](end_span). Найдутся \(N_1\) и \(N_2\), при \(n > \max(N_1, N_2)\) имеем \(|a_n-a|<\varepsilon\) и \(|a_n-b|<\varepsilon\)[span_46](start_span)[span_46](end_span). По неравенству треугольника: \(|a-b| \le |a-a_n| + |a_n-b| < 2\varepsilon = \frac{2}{3}|a-b|\)[span_47](start_span)[span_47](end_span). Противоречие, так как \(|a-b| > 0\)[span_48](start_span)[span_48](end_span).

Сходящаяся последовательность ограничена[span_49](start_span)[span_49](end_span).

Доказательство: Пусть \(a_n \to a\). Для \(\varepsilon = 1\) найдется \(N\): \(\forall n > N : |a_n - a| < 1\), откуда \(|a_n| < |a| + 1\)[span_50](start_span)[span_50](end_span). Положим \(C = \max\{|a_1|, \dots, |a_N|, |a|+1\}\)[span_51](start_span)[span_51](end_span). Тогда \(|a_n| \le C\) при всех \(n\)[span_52](start_span)[span_52](end_span).

Обратное неверно: \((-1)^n\) ограничена, но не сходится[span_53](start_span)[span_53](end_span).

№5 и №6 Бесконечно малые, бесконечно большие и отделимые от нуля[span_54](start_span)[span_54](end_span)[span_55](start_span)[span_55](end_span)

  • Бесконечно малая (б.м.): \(a_n \to 0 \iff \forall \varepsilon > 0 \exists N \forall n > N : |a_n| < \varepsilon\)[span_56](start_span)[span_56](end_span).
  • Бесконечно большая (б.б.): \(a_n \to \infty \iff \forall M > 0 \exists N \forall n > N : |a_n| > M\)[span_57](start_span)[span_57](end_span).
  • Ограниченная: \(\exists C > 0 \forall n : |c_n| \le C\)[span_58](start_span)[span_58](end_span).
  • Отделимая от нуля: \(\exists \delta > 0 \forall n : |c_n| \ge \delta\)[span_59](start_span)[span_59](end_span).

Свойства: \(\frac{1}{\text{б.м.}} = \text{б.б.}\) и \(\frac{1}{\text{б.б.}} = \text{б.м.}\)[span_60](start_span)[span_60](end_span).

Последовательность \((c_n)\) ограничена \(\iff (\frac{1}{c_n})\) отделима от нуля[span_61](start_span)[span_61](end_span).

Доказательство: Пусть \(c_n \ne 0\). Для положительных чисел \(|c_n| \le C \iff \left|\frac{1}{c_n}\right| \ge \frac{1}{C}\)[span_62](start_span)[span_62](end_span). Если \(|c_n| \le C\) при всех \(n\), то \(\delta = \frac{1}{C}\) подходит[span_63](start_span)[span_63](end_span). Если \(\left|\frac{1}{c_n}\right| \ge \delta\) при всех \(n\), то \(C = \frac{1}{\delta}\) подходит[span_64](start_span)[span_64](end_span).

Если \(a_n \to a \ne 0\), то \(\exists N \forall n > N : |a_n| > \frac{|a|}{2}\)[span_65](start_span)[span_65](end_span). Если к тому же все \(a_n \ne 0\), то \((a_n)\) отделима от нуля[span_66](start_span)[span_66](end_span).

Доказательство: Возьмем \(\varepsilon = \frac{|a|}{2} > 0\). \(\exists N \forall n > N : |a_n - a| < \frac{|a|}{2}\)[span_67](start_span)[span_67](end_span). Тогда \(|a_n| \ge |a| - |a - a_n| > \frac{|a|}{2}\)[span_68](start_span)[span_68](end_span). Для всех членов \(\delta = \min\{|a_1|, \dots, |a_N|, \frac{|a|}{2}\} > 0\)[span_69](start_span)[span_69](end_span).

Арифметические свойства предела[span_70](start_span)[span_70](end_span)

Пусть \(a_n \to a\), \(b_n \to b\). Тогда:

  1. \(a_n \pm b_n \to a \pm b\)[span_71](start_span)[span_71](end_span).
  2. \(a_n \cdot b_n \to a \cdot b\)[span_72](start_span)[span_72](end_span).
  3. \(\frac{a_n}{b_n} \to \frac{a}{b}\) (при \(b_n \ne 0, b \ne 0\))[span_73](start_span)[span_73](end_span).

Доказательство: Пусть \(a_n = a + \alpha_n\), \(b_n = b + \beta_n\), где \(\alpha_n, \beta_n\) - бесконечно малые[span_74](start_span)[span_74](end_span).

Для суммы: \(|(a_n+b_n) - (a+b)| \le |a_n-a| + |b_n-b|\). Сумма двух б.м. есть б.м[span_75](start_span)[span_75](end_span).

Для произведения: \(a_nb_n - ab = (a+\alpha_n)(b+\beta_n) - ab = a\beta_n + b\alpha_n + \alpha_n\beta_n\). Каждое слагаемое - б.м., их сумма - б.м[span_76](start_span)[span_76](end_span).

Для частного: \(\frac{a_n}{b_n} - \frac{a}{b} = \frac{1}{b} \cdot \frac{1}{b_n} \cdot (b\alpha_n - a\beta_n)\). Скобка - б.м., \(\frac{1}{b_n}\) ограничена (так как \((b_n)\) отделима от нуля), ограниченная на б.м. = б.м[span_77](start_span)[span_77](end_span).

№7 Предельный переход в неравенствах и теорема о двух милиционерах[span_78](start_span)[span_78](end_span)

Предельный переход: Если \(a_n \to a, b_n \to b\) и \(\forall n : a_n \ge b_n\), то \(a \ge b\)[span_79](start_span)[span_79](end_span).

Доказательство: Предположим, что \(a < b\). Возьмем \(\varepsilon_0 = \frac{b-a}{3} > 0\)[span_80](start_span)[span_80](end_span). Окрестности \(U_{\varepsilon_0}(a)\) и \(U_{\varepsilon_0}(b)\) не пересекаются, \(U_{\varepsilon_0}(a)\) строго левее \(U_{\varepsilon_0}(b)\), следовательно \(a_n < b_n\). Противоречие[span_81](start_span)[span_81](end_span).

О двух милиционерах: Если \(a_n \le b_n \le c_n\) при \(n \ge N_0\) и \(a_n \to a, c_n \to a\), то \(b_n \to a\)[span_82](start_span)[span_82](end_span).

Доказательство: Для \(\varepsilon > 0\) найдутся \(N_1, N_2\): \(a-\varepsilon < a_n\) и \(c_n < a+\varepsilon\)[span_83](start_span)[span_83](end_span). При \(n > \max(N_0, N_1, N_2)\) имеем \(a-\varepsilon < a_n \le b_n \le c_n < a+\varepsilon\), то есть \(|b_n - a| < \varepsilon\)[span_84](start_span)[span_84](end_span).

№8 Ограниченные подмножества и аксиома непрерывности[span_85](start_span)[span_85](end_span)[span_86](start_span)[span_86](end_span)

\(A \subset \mathbb{R}\) ограничено сверху, если \(\exists c \in \mathbb{R} \forall a \in A : a \le c\)[span_87](start_span)[span_87](end_span).

\(A \subset \mathbb{R}\) ограничено снизу, если \(\exists c \in \mathbb{R} \forall a \in A : a \ge c\)[span_88](start_span)[span_88](end_span).

Аксиома непрерывности (полноты): Если \(A, B \subset \mathbb{R}\) (\(A \ne \emptyset, B \ne \emptyset\)) и \(\forall a \in A, \forall b \in B : a \le b\), то \(\exists c \in \mathbb{R} \forall a \in A \forall b \in B : a \le c \le b\)[span_89](start_span)[span_89](end_span).

Верхняя грань множества \(A\) - любое \(c\), для которого \(\forall a \in A : a \le c\)[span_90](start_span)[span_90](end_span). Точная верхняя грань (sup A) - наименьшая из верхних граней[span_91](start_span)[span_91](end_span).

Непустое ограниченное сверху множество имеет супремум[span_92](start_span)[span_92](end_span).

Доказательство: Пусть \(B\) - множество всех верхних граней \(A\) (\(B \ne \emptyset\), так как \(A\) ограничено сверху)[span_93](start_span)[span_93](end_span). По аксиоме непрерывности \(\exists c: a \le c \le b\). Так как \(a \le c\), \(c\) - верхняя грань[span_94](start_span)[span_94](end_span). Так как \(c \le b\) \(\forall b \in B\), \(c\) - наименьшая верхняя грань. Значит \(c = \sup A\)[span_95](start_span)[span_95](end_span).

Теорема Вейерштрасса: Если \((a_n)\) возрастает и ограничена сверху, то она сходится[span_96](start_span)[span_96](end_span).

Доказательство: Пусть \(A = \{a_1, a_2, \dots\}\) ограничено сверху. \(\exists a = \sup A\)[span_97](start_span)[span_97](end_span). Проверим, что \(a_n \to a\). \(a\) - верхняя грань, \(a_n \le a\)[span_98](start_span)[span_98](end_span). Для \(\varepsilon > 0\), число \(a-\varepsilon\) не является верхней гранью, значит \(\exists N : a_N > a-\varepsilon\)[span_99](start_span)[span_99](end_span). Так как последовательность не убывает, при \(n > N : a-\varepsilon < a_N \le a_n \le a < a+\varepsilon\), следовательно \(|a_n - a| < \varepsilon\)[span_100](start_span)[span_100](end_span).

№14 Предел функции в точке[span_128](start_span)[span_128](end_span)[span_129](start_span)[span_129](end_span)

  • По Коши: \(\lim_{x \to x_0} f(x) = a \iff \forall \varepsilon > 0 \exists \delta > 0 \forall x : 0 < |x-x_0| < \delta \implies |f(x)-a| < \varepsilon\)[span_130](start_span)[span_130](end_span).
  • По Гейне: \(\lim_{x \to x_0} f(x) = a \iff \forall (x_n)\), если \(x_n \to x_0 (x_n \ne x_0)\), то \(f(x_n) \to a\)[span_131](start_span)[span_131](end_span).

Коши \(\implies\) Гейне: Для любого \(\delta\) из Коши, если \(x_n \to x_0\), то \(\exists N \forall n > N : 0 < |x_n - x_0| < \delta\), откуда \(|f(x_n)-a|<\varepsilon\)[span_133](start_span)[span_133](end_span)[span_134](start_span)[span_134](end_span).

Гейне \(\implies\) Коши: От противного. Пусть по Коши неверно: \(\exists \varepsilon_0 > 0 \forall \delta > 0 \exists x : 0 < |x-x_0| < \delta\) и \(|f(x)-a| \ge \varepsilon_0\)[span_135](start_span)[span_135](end_span). Возьмем \(\delta = 1/k\). Найдется последовательность \(x_k \to x_0\), для которой \(|f(x_k)-a| \ge \varepsilon_0\), что противоречит определению по Гейне[span_136](start_span)[span_136](end_span).

№15 Арифметика предела функции и теорема о двух милиционерах[span_137](start_span)[span_137](end_span)

Пусть \(f(x) \to a\), \(g(x) \to b\). Тогда \(f(x) \pm g(x) \to a \pm b\), \(f(x)g(x) \to ab\), \(\frac{f(x)}{g(x)} \to \frac{a}{b}\) (\(b \ne 0\))[span_138](start_span)[span_138](end_span).

Доказывается сведением к пределам последовательностей по определению Гейне: если \(x_n \to x_0\), то \(f(x_n) \to a\) и \(g(x_n) \to b\), и их арифметические комбинации сходятся по свойствам пределов последовательностей[span_139](start_span)[span_139](end_span).

Предельный переход в неравенствах: Если \(f(x) \ge g(x)\) в проколотой окрестности \(x_0\), то \(\lim f(x) \ge \lim g(x)\)[span_140](start_span)[span_140](end_span).

О двух милиционерах: Если \(f(x) \ge g(x) \ge h(x)\) и \(\lim f(x) = \lim h(x) = a\), то \(\lim g(x) = a\)[span_141](start_span)[span_141](end_span).

№16 Предел сложной функции[span_142](start_span)[span_142](end_span)

Пусть \(f(x) \to a\) при \(x \to x_0\), и \(g(y) \to b\) при \(y \to a\). Тогда \(g(f(x)) \to b\), если выполнено одно из условий[span_143](start_span)[span_143](end_span):
  • \(f(x) \ne a\) в проколотой окрестности \(x_0\)[span_144](start_span)[span_144](end_span).
  • \(g(a) = b\) (непрерывность функции \(g\))[span_145](start_span)[span_145](end_span).

Через определение по Гейне: если \(x_n \to x_0\), то \(y_n = f(x_n) \to a\)[span_146](start_span)[span_146](end_span). Если \(y_n \ne a\) или \(g(a) = b\), то мы имеем право утверждать, что \(g(y_n) \to b\)[span_147](start_span)[span_147](end_span).

№17 Первый замечательный предел[span_148](start_span)[span_148](end_span)

\(\lim_{x \to 0} \frac{\sin x}{x} = 1\)[span_149](start_span)[span_149](end_span).

Доказательство (геометрическое, для \(0 < x < \pi/2\)):

  • Сравним площади: \(S_{\triangle OAB} < S_{\text{сектора } OAB} < S_{\triangle OAC}\)[span_150](start_span)[span_150](end_span).
  • \(\frac{\sin x}{2} < \frac{x}{2} < \frac{\sin x}{2\cos x}\)[span_151](start_span)[span_151](end_span).
  • Делим на \(\frac{\sin x}{2}\): \(1 < \frac{x}{\sin x} < \frac{1}{\cos x}\)[span_152](start_span)[span_152](end_span).
  • Переворачиваем: \(\cos x < \frac{\sin x}{x} < 1\)[span_153](start_span)[span_153](end_span).
  • Так как \(\cos x \to 1\) при \(x \to 0\) (доказывается через \(0 \le 1 - \cos x = 2\sin^2(x/2) \le x^2/2 \to 0\)), по теореме о двух милиционерах предел равен \(1\)[span_154](start_span)[span_154](end_span).
