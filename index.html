0. ТЕОРИЯ ПРЕДЕЛОВ
Предел посл-ти: lim xn = a ⇔ ∀ε>0 ∃N∈ℕ ∀n>N: |xn − a| < ε.
Сходимость: сходится, если ∃ конечный lim xn = a ∈ ℝ (всякая сходящаяся ограничена). Иначе (lim = ±∞ или не ∃) — расходится.
Б.М. посл-ть: lim αn = 0 ⇔ ∀ε>0 ∃N∈ℕ ∀n>N: |αn| < ε. (Б.м. × огранич. = б.м.).
Б.Б. посл-ть: lim xn = ∞ ⇔ ∀E>0 ∃N∈ℕ ∀n>N: |xn| > E. (Связь: xn — б.б. ⇔ 1xn — б.м.).
Т. Вейерштрасса: всякая монотонная и ограниченная посл-ть сходится (не убывает + огр. сверху → sup; не возрастает + огр. снизу → inf).
№1. ИНДУКЦИЯ (ММИ) И БЕРНУЛЛИ
Неравенство Бернулли: (1 + x)n ≥ 1 + nx (при x > −1, n ∈ ℕ).
Шаги ММИ: 1) База (n=1): проверить равенство/нер-во. 2) Предположение (n=k): пусть верно для k. 3) Шаг (n=k+1): доказать для k+1, сведя к предположению.
Задача 1 (КР): 1·1 + 3·3 + 5·32 + … + (2n−1)3n−1 = (n−1)3n + 1.
• База n=1: 1 = (1−1)31 + 1 ⇒ 1 = 1 (верно).
• Пусть верно при n=k.
• Шаг k→k+1: ((k−1)3k + 1) + (2k+1)3k = 3k(k − 1 + 2k + 1) + 1 = 3k·3k + 1 = k·3k+1 + 1. ЧТД.

№7 + ФОТО 3–5. РЕКУРРЕНТНЫЙ ПРЕДЕЛ
Алгоритм:
1) Черновик (кандидат c): решаем xn+1 = xn ⇔ f(c) = c. Смотрим на x1 и выбираем интервал [x1; c] или [c; x1].
2) Ограниченность (по ММИ): доказываем xn ∈ [min; max]. База: n=1 верно. Шаг: пусть верно для xn, оцениваем xn+1 = f(xn) и получаем те же границы.
3) Монотонность (2 способа):
• Способ 1: знак разности xn+1 − xn ≥ 0 (возр.) или ≤ 0 (убыв.) с учетом границ xn.
• Способ 2: отношение xn+1xn ≥ 1 (возр.) или ≤ 1 (убыв.) (при xn>0).
4) Предел: монотонна + ограничена ⇒ по т. Вейерштрасса ∃ lim xn = a. Переходим к пределу в xn+1 = f(xn) ⇒ a = f(a), отбираем корень по границам.
Демка 1 (Фото 3–4): x1 = 3, xn+1 = √(2+3xn).
• Черновик: c2−3c−2=0 ⇒ c = 3+√172.
• ММИ: 3 ≤ xn ≤ 3+√172 ⇒ √11 ≤ √(2+3xn) ≤ 3+√172 (т.к. (3+√172)2 = 13+3√172).
• Монот.: xn+1−xn = −xn2+3xn+2√(2+3xn)+xn ≥ 0 на [3; 3+√172] ⇒ возрастает.
• По т. Вейерштрасса lim xn = (3+√17)/2.
Демка 2 (Фото 4–5): a1 = 1/2, an+1 = 12−an.
• Кандидат: c = 12−c ⇒ (c−1)2=0 ⇒ c=1.
• ММИ: an ∈ [1/2; 1] ⇒ 2−an ∈ [1; 3/2] ⇒ 12−an ∈ [2/3; 1] ⊂ [1/2; 1].
• Монот.: an+1−an = 12−an − an = (1−an)22−an ≥ 0 ⇒ возрастает.
• По т. Вейерштрасса lim an = 1.
Задача 7 (КР): x1 = 4, xn+1 = 3xn+2xn+2 = 3 − 4xn+2.
• Кандидат: c = 3c+2c+2 ⇒ c2−c−2=0 ⇒ c=2 (т.к. xn>0).
• ММИ: 2 ≤ xn ≤ 4 ⇒ 4 ≤ xn+2 ≤ 6 ⇒ 2 ≤ 3 − 4xn+2 ≤ 7/3 ≤ 4.
• Монот.: xn+1−xn = 2+xn−xn2xn+2 = −(xn−2)(xn+1)xn+2 ≤ 0 ⇒ убывает.
• По т. Вейерштрасса lim xn = 2.
