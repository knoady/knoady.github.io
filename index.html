№1 Высказывания, предикаты и логические операции

  • Высказывание - выражение, про которое можно сказать, истинно оно или ложно.
  • n-местный предикат - утверждение, зависящее от переменных, которое становится высказыванием при подстановке любых значений переменных.

№2 Метод математической индукции (ММИ)

Пусть P(n) - предикат, где n ∈ ℕ. Если истинны: (1) база P(1) и (2) переход P(k) ⇒ P(k+1), то ∀ n ∈ ℕ P(n) истинно.

Неравенство Бернулли: ∀ n ∈ ℕ, ∀ x ≥ -1: (1+x)n ≥ 1+nx.

Доказательство по ПМИ:

  • База: При n=1, ∀ x ≥ -1: (1+x)1 ≥ 1+1·x - верно.
  • Переход: Предположим, что P(k) истинно, то есть (1+x)k ≥ 1+kx. Хотим доказать P(k+1): (1+x)k+1 ≥ 1+(k+1)x.
  • (1+x)k+1 = (1+x)k · (1+x) ≥ (1+kx)(1+x) = 1+(k+1)x+kx2.
  • Поскольку kx2 ≥ 0, получаем (1+x)k+1 ≥ 1+(k+1)x. Переход верен.

№3 и №4 Перестановки, размещения и сочетания

Правило произведения: если первый объект выбирается m способами, а после этого второй k способами, то пару можно выбрать m · k способами.

  • Перестановка - упорядоченный набор из n различных элементов. Формула: Pn = n(n-1)… 2 · 1 = n!.
  • Размещение из n по k (k ≤ n) - упорядоченный набор k различных элементов из n-элементного множества. Формула: Ank = n!(n-k)!.
  • Сочетание из n по k - неупорядоченный выбор k элементов (k-элементное подмножество). Формула: Cnk = Ankk! = n!k!(n-k)!.

Полезные свойства:

  • Cnk = Cnn-k
  • Cnk + Cnk-1 = Cn+1k (правило Паскаля)
Бином Ньютона: (a+b)n = ∑k=0n Cnk ak bn-k.

Доказательство (в общем виде): (a+b)n = (a+b)(a+b)…(a+b) = an + Cn1 an-1b + … + Cnk an-kbk + … + Cnn bn.

Замечание: Cnn = Cn0 = 1, так как 0! = 1.

№4 Понятие последовательности и предела

Последовательность - набор вещественных чисел, пронумерованный натуральными индексами.

ε-окрестность точки a ∈ ℝ при ε > 0: Uε(a) = (a-ε, a+ε).

Предел последовательности: a - предел последовательности (an), если ∀ ε > 0 ∃ N=N(ε) ∀ n > N : |an - a| < ε.

Это равносильно a-ε < an < a+ε.

Единственность предела: Сходящаяся последовательность имеет только один предел.

Доказательство: Пусть an → a и an → b. Возьмем ε = |a-b| / 3 > 0. Найдутся N1 и N2, при n > max(N1, N2) имеем |an-a| < ε и |an-b| < ε. По неравенству треугольника: |a-b| ≤ |a-an| + |an-b| < 2ε = (2/3)|a-b|. Противоречие, так как |a-b| > 0.

Сходящаяся последовательность ограничена.

Доказательство: Пусть an → a. Для ε = 1 найдется N: ∀ n > N : |an - a| < 1, откуда |an| < |a| + 1. Положим C = max{|a1|, …, |aN|, |a|+1}. Тогда |an| ≤ C при всех n.

Обратное неверно: (-1)n ограничена, но не сходится.

№5 и №6 Бесконечно малые, бесконечно большие и отделимые от нуля

  • Бесконечно малая (б.м.): an → 0 ⇔ ∀ ε > 0 ∃ N ∀ n > N : |an| < ε.
  • Бесконечно большая (б.б.): an → ∞ ⇔ ∀ M > 0 ∃ N ∀ n > N : |an| > M.
  • Ограниченная: ∃ C > 0 ∀ n : |cn| ≤ C.
  • Отделимая от нуля: ∃ δ > 0 ∀ n : |cn| ≥ δ.

Свойства: 1 / (б.м.) = б.б. и 1 / (б.б.) = б.м.

Последовательность (cn) ограничена ⇔ (1/cn) отделима от нуля.

Доказательство: Пусть cn ≠ 0. Для положительных чисел |cn| ≤ C ⇔ |1/cn| ≥ 1/C. Если |cn| ≤ C при всех n, то δ = 1/C подходит. Если |1/cn| ≥ δ при всех n, то C = 1/δ подходит.

Если an → a ≠ 0, то ∃ N ∀ n > N : |an| > |a|/2. Если к тому же все an ≠ 0, то (an) отделима от нуля.

Доказательство: Возьмем ε = |a|/2 > 0. ∃ N ∀ n > N : |an - a| < |a|/2. Тогда |an| ≥ |a| - |a - an| > |a|/2. Для всех членов δ = min{|a1|, …, |aN|, |a|/2} > 0.

Арифметические свойства предела

Пусть an → a, bn → b. Тогда:

  1. an ± bn → a ± b
  2. an · bn → a · b
  3. an / bn → a / b (при bn ≠ 0, b ≠ 0)

Доказательство: Пусть an = a + αn, bn = b + βn, где αn, βn - бесконечно малые.

Для суммы: |(an+bn) - (a+b)| ≤ |an-a| + |bn-b|. Сумма двух б.м. есть б.м.

Для произведения: anbn - ab = (a+αn)(b+βn) - ab = aβn + bαn + αnβn. Каждое слагаемое - б.м., их сумма - б.м.

Для частного: an/bn - a/b = (1/b) · (1/bn) · (bαn - aβn). Скобка - б.м., 1/bn ограничена (так как (bn) отделима от нуля), ограниченная на б.м. = б.м.

№7 Предельный переход в неравенствах и теорема о двух милиционерах

Предельный переход: Если an → a, bn → b и ∀ n : an ≥ bn, то a ≥ b.

Доказательство: Предположим, что a < b. Возьмем ε0 = (b-a)/3 > 0. Окрестности Uε0(a) и Uε0(b) не пересекаются, Uε0(a) строго левее Uε0(b), следовательно an < bn. Противоречие.

О двух милиционерах: Если an ≤ bn ≤ cn при n ≥ N0 и an → a, cn → a, то bn → a.

Доказательство: Для ε > 0 найдутся N1, N2: a-ε < an и cn < a+ε. При n > max(N0, N1, N2) имеем a-ε < an ≤ bn ≤ cn < a+ε, то есть |bn - a| < ε.

№8 Ограниченные подмножества и аксиома непрерывности

A ⊂ ℝ ограничено сверху, если ∃ c ∈ ℝ ∀ a ∈ A : a ≤ c.

A ⊂ ℝ ограничено снизу, если ∃ c ∈ ℝ ∀ a ∈ A : a ≥ c.

Аксиома непрерывности (полноты): Если A, B ⊂ ℝ (A ≠ ∅, B ≠ ∅) и ∀ a ∈ A, ∀ b ∈ B : a ≤ b, то ∃ c ∈ ℝ ∀ a ∈ A ∀ b ∈ B : a ≤ c ≤ b.

Верхняя грань множества A - любое c, для которого ∀ a ∈ A : a ≤ c. Точная верхняя грань (sup A) - наименьшая из верхних граней.

Непустое ограниченное сверху множество имеет супремум.

Доказательство: Пусть B - множество всех верхних граней A (B ≠ ∅, так как A ограничено сверху). По аксиоме непрерывности ∃ c: a ≤ c ≤ b. Так как a ≤ c, c - верхняя грань. Так как c ≤ b для ∀ b ∈ B, c - наименьшая верхняя грань. Значит c = sup A.

Теорема Вейерштрасса: Если (an) возрастает и ограничена сверху, то она сходится.

Доказательство: Пусть A = {a1, a2, …} ограничено сверху. ∃ a = sup A. Проверим, что an → a. a - верхняя грань, an ≤ a. Для ε > 0, число a-ε не является верхней гранью, значит ∃ N : aN > a-ε. Так как последовательность не убывает, при n > N : a-ε < aN ≤ an ≤ a < a+ε, следовательно |an - a| < ε.

№10 Сходимость последовательности (1 + 1/n)n

limn→∞ (1 + 1/n)n = e ≈ 2.71.

(1) Докажем возрастание: Сравним an+1 и an. an+1 / an = … = (n+2)(n2+n+1) / (n+1)3 = (n3+3n2+3n+2) / (n3+3n2+3n+1) > 1.

(2) Докажем ограниченность сверху: По биному Ньютона (1 + 1/n)n ≤ 1 + 1 + 1/2! + … + 1/n! ≤ 1 + 1 + 1/(1·2) + … + 1/((n-1)n) = 3 - 1/n < 3.

Подпоследовательности и теорема Больцано-Вейерштрасса

Подпоследовательность: bk = ank, где n1 < n2 < …. Если an → a, то любая ank → a.

Частичный предел - предел какой-нибудь подпоследовательности.

Предельная точка: число a, в любой окрестности которого бесконечно много членов последовательности.

a - частичный предел ⇔ a - предельная точка.

⇒: Если ank → a, то ∀ k > K : ank ∈ Uε(a). Таких членов бесконечно много.

⇐: Строим по шагам для εk = 1/k. В U1/k(a) бесконечно много членов, выбираем nk > nk-1. Полученная подпоследовательность сходится к a.

Теорема Больцано-Вейерштрасса: Ограниченная последовательность имеет сходящуюся подпоследовательность.

Доказательство: Делим отрезок [A, B] пополам, выбираем половину с бесконечным числом членов, получаем вложенные отрезки [bk, ck]. По теореме Вейерштрасса их концы сходятся к общему пределу b, и существует подпоследовательность ank → b.

№13 Фундаментальные последовательности и критерий Коши

(an) фундаментальна (Коши), если ∀ ε > 0 ∃ N=N(ε) ∀ n,m > N : |an - am| < ε.

Критерий Коши: (an) сходится ⇔ (an) фундаментальна.

⇒: Пусть an → a. При n,m > N: |an - am| ≤ |an-a| + |am-a| < ε/2 + ε/2 = ε.

⇐: 1. Фундаментальная последовательность ограничена. 2. По теореме Больцано-Вейерштрасса ∃ ank → a. 3. Покажем, что an → a: |an - a| ≤ |an - ank| + |ank - a| < ε/2 + ε/2 = ε (при соответствующих n, nk > N).

№14 Предел функции в точке

  • По Коши: limx→x0 f(x) = a ⇔ ∀ ε > 0 ∃ δ > 0 ∀ x : 0 < |x-x0| < δ ⇒ |f(x)-a| < ε.
  • По Гейне: limx→x0 f(x) = a ⇔ ∀ (xn), если xn → x0 (xn ≠ x0), то f(xn) → a.
Определения по Коши и по Гейне эквивалентны.

Коши ⇒ Гейне: Для любого δ из Коши, если xn → x0, то ∃ N ∀ n > N : 0 < |xn - x0| < δ, откуда |f(xn)-a| < ε.

Гейне ⇒ Коши: От противного. Пусть по Коши неверно: ∃ ε0 > 0 ∀ δ > 0 ∃ x : 0 < |x-x0| < δ и |f(x)-a| ≥ ε0. Возьмем δ = 1/k. Найдется последовательность xk → x0, для которой |f(xk)-a| ≥ ε0, что противоречит определению по Гейне.

№15 Арифметика предела функции и теорема о двух милиционерах

Пусть f(x) → a, g(x) → b. Тогда f(x) ± g(x) → a ± b, f(x)g(x) → ab, f(x) / g(x) → a / b (b ≠ 0).

Доказывается сведением к пределам последовательностей по определению Гейне: если xn → x0, то f(xn) → a и g(xn) → b, и их арифметические комбинации сходятся по свойствам пределов последовательностей.

Предельный переход в неравенствах: Если f(x) ≥ g(x) в проколотой окрестности x0, то lim f(x) ≥ lim g(x).

О двух милиционерах: Если f(x) ≥ g(x) ≥ h(x) и lim f(x) = lim h(x) = a, то lim g(x) = a.

№16 Предел сложной функции

Пусть f(x) → a при x → x0, и g(y) → b при y → a. Тогда g(f(x)) → b, если выполнено одно из условий:
  • f(x) ≠ a в проколотой окрестности x0.
  • g(a) = b (непрерывность функции g).

Через определение по Гейне: если xn → x0, то yn = f(xn) → a. Если yn ≠ a или g(a) = b, то мы имеем право утверждать, что g(yn) → b.

№17 Первый замечательный предел

limx→0 sin xx = 1.

Доказательство (геометрическое, для 0 < x < π/2):

  • Сравним площади: S△OAB < Sсектора OAB < S△OAC.
  • (sin x) / 2 < x / 2 < (sin x) / (2cos x).
  • Делим на (sin x) / 2: 1 < x / sin x < 1 / cos x.
  • Переворачиваем: cos x < (sin x) / x < 1.
  • Так как cos x → 1 при x → 0 (доказывается через 0 ≤ 1 - cos x = 2sin2(x/2) ≤ x2/2 → 0), по теореме о двух милиционерах предел равен 1.
