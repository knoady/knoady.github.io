База и Определения

Теория пределов последовательностей

1. Определение предела последовательности

$\lim_{n\to\infty} x_n = a$

Число $a \in \mathbb{R}$ называется пределом последовательности $(x_n)$, если для любого сколь угодно малого $\varepsilon > 0$ существует номер $N(\varepsilon) \in \mathbb{N}$ такой, что для всех $n > N(\varepsilon)$ выполняется неравенство $|x_n - a| < \varepsilon$:

$$\lim_{n\to\infty} x_n = a \iff \forall \varepsilon > 0 \ \exists N(\varepsilon) \in \mathbb{N} \ \forall n > N: \ |x_n - a| < \varepsilon$$

Геометрический смысл: в любой $\varepsilon$-окрестности $(a-\varepsilon; a+\varepsilon)$ точки $a$ содержатся все члены последовательности, начиная с некоторого номера $N+1$ (вне окрестности — лишь конечное число членов).

2. Сходимость и расходимость

$a \in \mathbb{R}$ vs $\pm\infty$
  • Сходящаяся последовательность: последовательность, которая имеет конечный предел $a \in \mathbb{R}$ ($\exists \lim_{n\to\infty} x_n = a, \ |a| < \infty$).
  • Расходящаяся последовательность: последовательность, которая не имеет конечного предела (её предел равен $+\infty$, $-\infty$, $\infty$ или вообще не существует, как у $(-1)^n$).

Важные свойства сходящихся: предел единственен; всякая сходящаяся последовательность ограничена ($\exists C > 0 \ \forall n: |x_n| \le C$). Обратное неверно: $(-1)^n$ ограничена, но расходится!

3. Теорема Вейерштрасса

Ключ к №7

Всякая монотонная и ограниченная последовательность сходится (имеет конечный предел):

1) Если $(x_n)$ не убывает ($x_{n+1} \ge x_n$) и ограничена сверху ($x_n \le M$), то: $$\exists \lim_{n\to\infty} x_n = \sup_{n\in\mathbb{N}} \{x_n\} \le M$$
2) Если $(x_n)$ не возрастает ($x_{n+1} \le x_n$) и ограничена снизу ($x_n \ge m$), то: $$\exists \lim_{n\to\infty} x_n = \inf_{n\in\mathbb{N}} \{x_n\} \ge m$$

4. Бесконечно малая (б.м.)

$\lim \alpha_n = 0$

Последовательность $(\alpha_n)$ называется бесконечно малой (б.м.), если её предел равен нулю:

$$\lim_{n\to\infty} \alpha_n = 0 \iff \forall \varepsilon > 0 \ \exists N(\varepsilon)\in\mathbb{N} \ \forall n > N: \ |\alpha_n| < \varepsilon$$
  • Связь с пределом: $\lim_{n\to\infty} x_n = a \iff x_n = a + \alpha_n$, где $\alpha_n$ — б.м.
  • Супер-свойство (для $\cos(n!)$ и $\sin n$): произведение б.м. последовательности на ограниченную есть б.м. последовательность ($\frac{\cos(n!)}{n} \to 0$).

5. Бесконечно большая (б.б.) последовательность и связь с б.м.

$\lim x_n = \infty$

Последовательность $(x_n)$ называется бесконечно большой (б.б.), если для любого сколь угодно большого $M > 0$ существует номер $N(M)\in\mathbb{N}$ такой, что для всех $n > N$:

$$\lim_{n\to\infty} x_n = \infty \iff \forall M > 0 \ \exists N\in\mathbb{N} \ \forall n > N: \ |x_n| > M$$
Частные случаи знака и теорема о связи б.б. и б.м.:
• $\lim x_n = +\infty \iff \forall M > 0 \ \exists N \ \forall n > N: \ x_n > M$
• $\lim x_n = -\infty \iff \forall M > 0 \ \exists N \ \forall n > N: \ x_n < -M$
Теорема о связи: Если $(x_n)$ — б.б. ($\forall n: x_n \neq 0$), то $\left(\frac{1}{x_n}\right)$ — б.м. И наоборот: если $(\alpha_n)$ — б.м. ($\alpha_n \neq 0$), то $\left(\frac{1}{\alpha_n}\right)$ — б.б.
Задание №1 КР

Метод математической индукции (ММИ) и неравенство Бернулли

Алгоритм доказательства по ММИ (4 шага) $P(1) \land (P(k)\Rightarrow P(k+1))$

  1. 1. База индукции ($n = 1$ или $n = n_0$): подставляем $n = 1$ в левую и правую части утверждения $P(1)$ и проверяем, что равенство/неравенство верно.
  2. 2. Предположение индукции ($n = k$): пишем фразу: «Предположим, что утверждение $P(k)$ верно при некотором натуральном $n = k$» (и выписываем само равенство для $k$).
  3. 3. Индукционный шаг ($n = k + 1$): доказываем верность $P(k+1)$, обязательно используя предположение $P(k)$. • Для сумм: заменяем сумму первых $k$ слагаемых по предположению и прибавляем $(k+1)$-е слагаемое.
    • Для делимости/неравенств: выделяем часть из $P(k)$ и оцениваем хвост.
  4. 4. Вывод: «По принципу математической индукции утверждение верно для всех $n \in \mathbb{N}$. Ч.т.д.»
Неравенство Бернулли Важная формула

Для любого вещественного $x \ge -1$ и любого натурального $n \in \mathbb{N}$:

$$(1 + x)^n \ge 1 + nx$$

*При $x \neq 0$ и $n \ge 2$ неравенство строгое: $(1+x)^n > 1 + nx$. Доказывается по ММИ: $(1+x)^{k+1} = (1+x)^k(1+x) \ge (1+kx)(1+x) = 1 + (k+1)x + kx^2 \ge 1 + (k+1)x$.

Эталон из КР (Фото 1) Задание №1

Докажите методом математической индукции, что для всех натуральных $n$ справедливо равенство:

$$1 \cdot 1 + 3 \cdot 3 + 5 \cdot 3^2 + \dots + (2n - 1) \cdot 3^{n-1} = (n - 1)3^n + 1$$
▶ Пошаговое чистовое оформление для КР
1) База индукции ($n = 1$):
Левая часть: $(2\cdot 1 - 1)\cdot 3^{1-1} = 1 \cdot 3^0 = 1$.
Правая часть: $(1 - 1)\cdot 3^1 + 1 = 0 + 1 = 1$.
$1 = 1$ — база верна.
2) Предположение индукции ($n = k$):
Пусть при $n = k$ равенство верно: $$1\cdot 1 + 3\cdot 3 + \dots + (2k - 1)\cdot 3^{k-1} = (k - 1)3^k + 1$$
3) Шаг индукции ($n = k + 1$):
Докажем, что при $n = k+1$ сумма равна $((k+1)-1)3^{k+1} + 1 = k\cdot 3^{k+1} + 1$.
Запишем левую часть для $n = k+1$, выделив сумму первых $k$ слагаемых: $$\underbrace{1\cdot 1 + 3\cdot 3 + \dots + (2k-1)3^{k-1}}_{\text{по предположению } = (k-1)3^k + 1} + (2(k+1)-1)3^{(k+1)-1}$$ $$= (k - 1)3^k + 1 + (2k + 1)3^k = 3^k \cdot (k - 1 + 2k + 1) + 1$$ $$= 3^k \cdot (3k) + 1 = k \cdot 3^{k+1} + 1$$ Получили в точности правую часть при $n = k + 1$.
4) Вывод: По принципу ММИ равенство верно для любого $n \in \mathbb{N}$. Ч.т.д.
Задание №2 КР

Бином Ньютона и число сочетаний $C_n^k$

Формулы $C_n^k$ и Бинома Ньютона

Число сочетаний из $n$ по $k$:
$$C_n^k = \binom{n}{k} = \frac{n!}{k!(n-k)!}$$
Практический счёт: $\frac{n(n-1)\dots(n-k+1)}{1\cdot 2 \dots k}$
Свойства $C_n^k$:
• $C_n^0 = C_n^n = 1, \quad C_n^1 = n$
• $C_n^k = C_n^{n-k}$ (симметрия)
• $C_n^k + C_n^{k+1} = C_{n+1}^{k+1}$ (Паскаль)
• $\sum_{k=0}^n C_n^k = 2^n$
Формула бинома Ньютона:
$$(a + b)^n = \sum_{k=0}^{n} C_n^k \, a^{n-k} \, b^k = C_n^0 a^n + C_n^1 a^{n-1}b + \dots + C_n^n b^n$$
Общий $(k+1)$-й член разложения: $T_{k+1} = C_n^k \, a^{n-k} \, b^k \quad (k = 0, 1, \dots, n)$
Эталон из КР (Фото 1) Задание №2

Найдите член разложения бинома, содержащий $x^4$:

$$\left(\sqrt{x} + \sqrt[3]{x}\right)^9$$
▶ Пошаговое решение
1) Запишем корни в виде степеней: $\sqrt{x} = x^{1/2}$, $\sqrt[3]{x} = x^{1/3}$, $n = 9$.
2) Составим общий член разложения $T_{k+1}$: $$T_{k+1} = C_9^k \cdot \left(x^{1/2}\right)^{9-k} \cdot \left(x^{1/3}\right)^k = C_9^k \cdot x^{\frac{9-k}{2} + \frac{k}{3}} = C_9^k \cdot x^{\frac{27 - 3k + 2k}{6}} = C_9^k \cdot x^{\frac{27-k}{6}}$$
3) Найдём $k$, при котором степень $x$ равна $4$: $$\frac{27 - k}{6} = 4 \implies 27 - k = 24 \implies k = 3$$
4) Вычислим биномиальный коэффициент $C_9^3$: $$C_9^3 = \frac{9!}{3!\cdot 6!} = \frac{9 \cdot 8 \cdot 7}{3 \cdot 2 \cdot 1} = 3 \cdot 4 \cdot 7 = 84$$
Ответ: $T_4 = 84x^4$ (или коэффициент равен $84$).
Задания №3, №4, №5 (а, б) КР

Асимптотика, сопряженные выражения и пределы дробей

Формулы домножения на сопряженное ($\infty - \infty$)

Квадратные корни ($a^2 - b^2$): $$\sqrt{A} - B = \frac{A - B^2}{\sqrt{A} + B}$$
Кубические корни ($a^3 - b^3$): $$\sqrt[3]{A} - B = \frac{A - B^3}{\sqrt[3]{A^2} + B\sqrt[3]{A} + B^2}$$
Корни 4-й степени ($a^4 - b^4$, для Задания №3!): $$a - b = \frac{a^4 - b^4}{a^3 + a^2b + ab^2 + b^3} = \frac{a^4 - b^4}{(a+b)(a^2+b^2)}$$ Лайфхак: если $a \sim n$ и $b = n$, то знаменатель $a^3 + a^2b + ab^2 + b^3 \sim n^3 + n^3 + n^3 + n^3 = 4n^3$.

Отношение многочленов ($\frac{\infty}{\infty}$) и разность дробей

При $n \to \infty$ оставляем только старшие степени в числителе и знаменателе (или делим числитель и знаменатель на старшую степень $n^{\max}$): $$\lim_{n\to\infty} \frac{a_p n^p + \dots + a_0}{b_q n^q + \dots + b_0} = \begin{cases} \frac{a_p}{b_q}, & p = q \\ 0, & p < q \\ \pm\infty, & p > q \end{cases}$$
Ловушка в №5а (разность двух дробей $\infty - \infty$):
Сначала проверь, не сокращается ли одна из дробей на $n$! Затем приведи к общему знаменателю — старшие степени взаимно уничтожатся, и останется стандартный предел отношения многочленов.
Задание №3 КР (Фото 1) Корень 4-й степени

Найдите предел последовательности (или её главную часть):

$$\lim_{n\to\infty} \left(\sqrt[4]{n^4 + 5n^2 - 2 + \cos(n!)} - n\right)$$
▶ Решение (предел и асимптотика)
Пусть $a = \sqrt[4]{n^4 + 5n^2 - 2 + \cos(n!)}$ и $b = n$. Домножим на сопряженное по формуле $a - b = \frac{a^4 - b^4}{a^3 + a^2b + ab^2 + b^3}$:
Числитель: $a^4 - b^4 = (n^4 + 5n^2 - 2 + \cos(n!)) - n^4 = 5n^2 - 2 + \cos(n!)$.
Знаменатель при $n\to\infty$: так как $a = n\sqrt[4]{1 + \frac{5}{n^2} + \dots} \sim n$, каждое из 4 слагаемых ($a^3, a^2b, ab^2, b^3$) эквивалентно $n^3$, значит знаменатель $\sim 4n^3$.
Тогда общий член последовательности: $$x_n = \frac{5n^2 - 2 + \cos(n!)}{a^3 + a^2b + ab^2 + b^3} \sim \frac{5n^2}{4n^3} = \frac{5}{4n} \to 0$$ (так как $|\cos(n!)| \le 1$ — ограниченная величина).
Ответ: Предел равен $0$; главная часть (асимптотика) равна $\frac{5}{4n}$.

Задание №5б КР (Фото 1–2) Два корня
$$\lim_{n\to\infty} \frac{\sqrt{n^2+6n}-n}{\sqrt{n^2+10n}-n}$$
▶ Решение №5б
Домножаем и числитель, и знаменатель на их сопряжённые выражения: $$\lim_{n\to\infty} \frac{(n^2+6n-n^2)(\sqrt{n^2+10n}+n)}{(n^2+10n-n^2)(\sqrt{n^2+6n}+n)} = \lim_{n\to\infty} \frac{6\cancel{n} \cdot \cancel{n}(\sqrt{1+10/n}+1)}{10\cancel{n} \cdot \cancel{n}(\sqrt{1+6/n}+1)} = \frac{6 \cdot 2}{10 \cdot 2} = \mathbf{\frac{3}{5}}$$
Задание №5а КР (Фото 1–2) Неопределенность $\infty - \infty$
$$\lim_{n\to\infty} \left(\frac{2n^3+1}{n^2+1} - \frac{2n^3+n^2}{n^2+n}\right)$$
Решение: Заметим, что во второй дроби сокращается $n$: $\frac{2n^3+n^2}{n^2+n} = \frac{n(2n^2+n)}{n(n+1)} = \frac{2n^2+n}{n+1}$. Приводим к общему знаменателю: $$\lim_{n\to\infty} \frac{(2n^3+1)(n+1) - (2n^2+n)(n^2+1)}{(n^2+1)(n+1)} = \lim_{n\to\infty} \frac{(2n^4 + 2n^3 + n + 1) - (2n^4 + n^3 + 2n^2 + n)}{n^3 + n^2 + n + 1} = \lim_{n\to\infty} \frac{n^3 - 2n^2 + 1}{n^3 + n^2 + n + 1} = \mathbf{1}$$

Формулы с Фото 6 (с обобщениями) и сходимость ряда

Все пределы с Фото 6 + обобщения

Фото 6
(a) Геометрическая последовательность $a_n = q^n, \ q \in \mathbb{R}$:
$$\lim_{n\to\infty} q^n = \begin{cases} 0, & \text{если } |q| < 1 \quad (\text{б.м.}) \\ 1, & \text{если } q = 1 \\ +\infty, & \text{если } q > 1 \quad (\text{б.б.}) \\ \text{не существует}, & \text{если } q \le -1 \quad (\text{расходится}) \end{cases}$$
(b) Корень из константы ($a > 0$):
$$a_n = \sqrt[n]{a} \implies \lim_{n\to\infty} \sqrt[n]{a} = 1$$ Док-во: через неравенство Бернулли.
(c) Корень $n$-й степени из $n$:
$$a_n = \sqrt[n]{n} \implies \lim_{n\to\infty} \sqrt[n]{n} = 1$$ Следствие: $\lim \sqrt[n]{n^k} = 1$, $\lim \sqrt[n]{P_k(n)} = 1$.
(d) $a_n = \dfrac{n^2}{2^n}$ + обобщение (степень против показательной):
$$\lim_{n\to\infty} \frac{n^2}{2^n} = 0 \quad \Longrightarrow \quad \mathbf{\text{Обобщение:}} \ \lim_{n\to\infty} \frac{n^k}{q^n} = 0 \quad (\forall k \in \mathbb{R}, \ \forall q > 1)$$ Показательная функция $q^n$ ($q>1$) при $n\to\infty$ растет быстрее любой степени $n^k$.
(e) $a_n = \dfrac{2^n}{n!}$ + обобщение (показательная против факториала):
$$\lim_{n\to\infty} \frac{2^n}{n!} = 0 \quad \Longrightarrow \quad \mathbf{\text{Обобщение:}} \ \lim_{n\to\infty} \frac{q^n}{n!} = 0 \quad (\forall q \in \mathbb{R})$$ Факториал $n!$ растет быстрее любой показательной функции $q^n$. Иерархия роста: $\ln^\alpha n \ll n^k \ll q^n \ll n! \ll n^n$.
Задание №6 КР (Фото 1–2) Сходимость ряда

Исследуйте на сходимость ряд с общим членом (по 2-му признаку сравнения / асимптотике):

$$a_n = \sqrt{\frac{5^n + 2^n + 3n}{3n^3 - 2n}}$$
1) Необходимый признак сходимости ряда $\sum a_n$: если ряд сходится, то $\lim_{n\to\infty} a_n = 0$. Если $\lim_{n\to\infty} a_n \neq 0 \implies$ ряд расходится!
2) 2-й (предельный) признак сравнения: если $a_n, b_n > 0$ и $\lim_{n\to\infty} \frac{a_n}{b_n} = c \in (0; +\infty)$, то ряды $\sum a_n$ и $\sum b_n$ сходятся или расходятся одновременно (эталон Дирихле $\sum \frac{1}{n^p}$ сходится при $p > 1$, расходится при $p \le 1$).
▶ Решение Задания №6
1) Выделим главную часть $b_n$ при $n \to \infty$:
В числителе под корнем доминирует показательная функция $5^n$ (т.к. $2^n/5^n \to 0$ и $3n/5^n \to 0$), в знаменателе доминирует $3n^3$: $$a_n \sim b_n = \sqrt{\frac{5^n}{3n^3}} = \frac{(\sqrt{5})^n}{\sqrt{3}\cdot n^{3/2}} \quad \left(\lim_{n\to\infty} \frac{a_n}{b_n} = 1\right)$$
2) Найдём предел общего члена (по формуле (d) с Фото 6):
Так как основание $\sqrt{5} > 1$, показательная функция растет быстрее степенной $n^{3/2}$: $$\lim_{n\to\infty} a_n = \lim_{n\to\infty} \frac{(\sqrt{5})^n}{\sqrt{3}\, n^{3/2}} = +\infty \neq 0$$ (Если сравнивать по 2-му признаку с расходящимся рядом $b_n = \frac{1}{n}$: $\lim \frac{a_n}{1/n} = +\infty \implies$ ряд $a_n$ тем более расходится).
Ответ: Ряд расходится (не выполнен даже необходимый признак сходимости: $\lim_{n\to\infty} a_n = \infty \neq 0$).
Задание №7 КР + Фото 3, 4, 5

Гайд по рекуррентным последовательностям (по рукописному конспекту)

Универсальный алгоритм нахождения предела рекуррентной последовательности: «1) Ограниченность → 2) Монотонность → 3) Предел ВСЁ!»

По фото 3, 4, 5
Шаг 0. Черновик (ищем кандидата $c$)

Приравниваем $x_{n+1} = x_n = c$, решаем уравнение $c = f(c)$ и по логике (считаем $x_1, x_2$, смотрим куда движется последовательность и какого она знака) выбираем нужный корень $c$. Это черновик — понимаем границы отрезка $[x_1; c]$ или $[c; x_1]$!

1) По ММИ доказываем ограниченность

Пишем: «Докажем по индукции, что $x_n \in [m; M]$» (где границы — это $x_1$ и кандидат $c$).
• База: $x_1 \in [m; M]$ $\checkmark$
• Шаг: пусть верно для $x_n$ ($m \le x_n \le M$). Оцениваем выражение для $x_{n+1} = f(x_n)$ и получаем $m \le x_{n+1} \le M$. Ура, ч.т.д.!

2) Доказываем монотонность (2 варианта)

Выбираем, что удобнее анализировать, опираясь на уже доказанный интервал $x_n \in [m; M]$:
• Вариант 1 (разность): $x_{n+1} - x_n \ge 0$ (растет) или $\le 0$ (убывает).
• Вариант 2 (деление): $\frac{x_{n+1}}{x_n} \ge 1$ или $\le 1$ (при $x_n > 0$).

3) Находим предел (Т. Вейерштрасса)

Пишем: «Монотонна + ограничена $\implies$ по т. Вейерштрасса предел $\exists$ и конечен: $\lim_{n\to\infty} x_n = a$».
Переходим к пределу (как на фото 4–5):
$x_n \to a$ и $x_{n+1} = f(x_n) \to f(a)$ — они должны быть равны $\implies$ решаем $a = f(a)$ и отбираем корень из $[m; M]$.

Демка №1 (Фото 3–4) Корень
$$x_1 = 3, \quad x_{n+1} = \sqrt{2 + 3x_n}$$
▶ Полный конспект с Фото 3–4
0) Черновик: $\sqrt{2+3c}=c \implies c^2-3c-2=0 \implies c = \frac{3\pm\sqrt{17}}{2}$. С учетом $x_1 = 3$ и того, что последовательность растет ($x_2 = \sqrt{11} \approx 3{,}31 > 3$), выбираем $c = \frac{3+\sqrt{17}}{2}$.
1) Ограниченность по ММИ: докажем, что $x_n \in \left[3; \frac{3+\sqrt{17}}{2}\right]$.
• База: $x_1 = 3 \in \left[3; \frac{3+\sqrt{17}}{2}\right]$ $\checkmark$
• Шаг: пусть $3 \le x_n \le \frac{3+\sqrt{17}}{2}$. Тогда: $$9 \le 3x_n \le \frac{9+3\sqrt{17}}{2} \implies \underbrace{\sqrt{11}}_{>3} \le \sqrt{3x_n+2} \le \sqrt{\frac{13+3\sqrt{17}}{2}} = \frac{3+\sqrt{17}}{2}$$ Значит $x_{n+1} \in \left[3; \frac{3+\sqrt{17}}{2}\right]$, ура, ч.т.д.!
2) Монотонность (разностью + методом интервалов): $$x_{n+1} - x_n = \sqrt{2+3x_n} - x_n = \frac{-x_n^2 + 3x_n + 2}{\sqrt{2+3x_n} + x_n} \ge 0$$ т.к. корни числителя $\frac{3-\sqrt{17}}{2}$ и $\frac{3+\sqrt{17}}{2}$, парабола ветвями вниз ($- \ [+] \ -$), и весь наш отрезок $\left[3; \frac{3+\sqrt{17}}{2}\right]$ лежит в зоне «$+$». Значит, не убывает!
3) Предел: Монотонна + ограничена $\implies$ по т. Вейерштрасса $\exists \lim x_n = a$. Из $a = \sqrt{2+3a}$ получаем $a = \frac{3+\sqrt{17}}{2}$ (корень $\frac{3-\sqrt{17}}{2} < 0$ не подходит).
Демка №2 с консы (Фото 4–5) Дробь
$$a_1 = \frac{1}{2}, \quad a_{n+1} = \frac{1}{2 - a_n}$$
▶ Полный конспект с Фото 4–5
0) Черновик: $c = \frac{1}{2-c} \implies 2c - c^2 = 1 \implies (c-1)^2 = 0 \implies c = 1$. Выбираем интервал $\left[\frac{1}{2}; 1\right]$.
1) Ограниченность по ММИ: докажем, что $a_n \in \left[\frac{1}{2}; 1\right]$.
• База: $a_1 = \frac{1}{2} \in \left[\frac{1}{2}; 1\right]$ $\checkmark$
• Шаг: пусть $\frac{1}{2} \le a_n \le 1$. Тогда: $$-1 \le -a_n \le -\frac{1}{2} \implies 1 \le 2 - a_n \le \frac{3}{2}$$ $$1 \ge \frac{1}{2 - a_n} \ge \frac{2}{3} \in \left[\frac{1}{2}; 1\right] \implies a_{n+1} \in \left[\frac{1}{2}; 1\right] \ \checkmark$$
2) Монотонность: $$a_{n+1} - a_n = \frac{1}{2 - a_n} - a_n = \frac{1 - 2a_n + a_n^2}{2 - a_n} = \frac{(a_n - 1)^2}{2 - a_n} \ge 0$$ так как числитель $(a_n-1)^2 \ge 0$, а знаменатель $2 - a_n \ge 1 > 0$. Последовательность возрастает!
3) Предел: По т. Вейерштрасса предел существует. Так как $a_n \to a$ и $a_{n+1} = \frac{1}{2-a_n} \to \frac{1}{2-a}$, получаем $a = \frac{1}{2-a} \implies \mathbf{a = 1}$.
Задание №7 из КР (Фото 2) Готовый ответ
$$x_1 = 4, \quad x_{n+1} = \frac{3x_n + 2}{x_n + 2}$$
▶ Решение №7 строго по вашему алгоритму
0) Черновик: $c = \frac{3c+2}{c+2} \implies c^2 + 2c = 3c + 2 \implies c^2 - c - 2 = 0 \implies c = 2$ или $c = -1$. Т.к. $x_1 = 4 > 0$, все $x_n > 0$, выбираем $c = 2$. Последовательность убывает от $4$ к $2 \implies$ отрезок $[2; 4]$.
1) Ограниченность по ММИ: докажем, что $x_n \in [2; 4]$.
Выделим целую часть: $x_{n+1} = \frac{3(x_n+2)-4}{x_n+2} = 3 - \frac{4}{x_n+2}$.
• База: $x_1 = 4 \in [2; 4]$ $\checkmark$
• Шаг: пусть $2 \le x_n \le 4$. Тогда: $$4 \le x_n + 2 \le 6 \implies 1 \ge \frac{4}{x_n+2} \ge \frac{2}{3} \implies 2 \le 3 - \frac{4}{x_n+2} \le \frac{7}{3} < 4$$ Значит $x_{n+1} \in [2; 4]$. Ч.т.д.!
2) Монотонность: $$x_{n+1} - x_n = \frac{3x_n + 2}{x_n + 2} - x_n = \frac{-x_n^2 + x_n + 2}{x_n + 2} = -\frac{(x_n - 2)(x_n + 1)}{x_n + 2} \le 0$$ так как при $x_n \in [2; 4]$ имеем $x_n - 2 \ge 0$, $x_n + 1 > 0$, $x_n + 2 > 0$. Последовательность не возрастает (убывает).
3) Предел: По т. Вейерштрасса $\exists \lim_{n\to\infty} x_n = a \in [2; 4]$. Из $a = \frac{3a+2}{a+2} \implies a^2 - a - 2 = 0$. Так как $a \in [2; 4]$, корень $a = -1$ не подходит. Ответ: $\lim_{n\to\infty} x_n = 2$.
Задания №8 и №5в КР + Фото 7

Замечательные пределы и все формулы с Фото 7

1-й и 2-й замечательные пределы + Фото 7

Фото 7
1-й замечательный ($\alpha_n \to 0$):
$$\lim_{n\to\infty} \frac{\sin \alpha_n}{\alpha_n} = 1, \quad \lim_{n\to\infty} \frac{\tan \alpha_n}{\alpha_n} = 1$$
2-й замечательный ($\alpha_n \to 0$):
$$\lim_{n\to\infty} \left(1 + \frac{1}{n}\right)^n = e, \quad \lim_{\alpha_n\to 0} (1+\alpha_n)^{\frac{1}{\alpha_n}} = e$$
Все готовые формулы с Фото 7:
$$\lim_{n\to\infty} \left(1 - \frac{1}{n}\right)^n = \frac{1}{e} = e^{-1}$$ $$\lim_{n\to\infty} \left(1 + \frac{1}{kn}\right)^n = e^{1/k}, \qquad \lim_{n\to\infty} \left(1 - \frac{1}{kn}\right)^n = e^{-1/k}$$ $$\lim_{n\to\infty} \left(1 + \frac{k}{n}\right)^n = e^k, \qquad \lim_{n\to\infty} \left(1 - \frac{k}{n}\right)^n = e^{-k}$$ $$\lim_{n\to\infty} \left(1 + \frac{p}{n}\right)^n = e^p, \quad p \in \mathbb{Q} \ (\text{и } \mathbb{R})$$
Универсальный приём для неопределенности $\left[1^\infty\right]$:
Если $\alpha_n \to 0$ и $\beta_n \to \infty$, то выделяем единицу в основании $(U_n)^{\beta_n} = (1 + (U_n - 1))^{\beta_n}$: $$\lim_{n\to\infty} (1 + \alpha_n)^{\beta_n} = \lim_{n\to\infty} \left((1 + \alpha_n)^{\frac{1}{\alpha_n}}\right)^{\alpha_n \cdot \beta_n} = e^{\lim_{n\to\infty} (\alpha_n \cdot \beta_n)}$$
Задание №5в КР (Фото 1–2) 2-й замеч. + $\sqrt[n]{a}$
$$\lim_{n\to\infty} \left(\left(\frac{5n - 3}{5n}\right)^{5n - 2} + \sqrt[n]{3}\right)$$
▶ Решение №5в
1) Первое слагаемое: $\left(\frac{5n-3}{5n}\right)^{5n-2} = \left(1 - \frac{3}{5n}\right)^{5n} \cdot \left(1 - \frac{3}{5n}\right)^{-2}$.
По формуле со 2-м замечательным пределом: $\lim \frac{-3}{5n} \cdot (5n-2) = -3 \implies \lim \left(1 - \frac{3}{5n}\right)^{5n-2} = e^{-3}$.
2) Второе слагаемое (по формуле (b) с Фото 6): $\lim_{n\to\infty} \sqrt[n]{3} = 1$.
Ответ: $e^{-3} + 1 = \frac{1}{e^3} + 1$.
Задание №8 КР (Фото 2) Степень $n^2$

Вычислите предел со вторым замечательным пределом:

$$\lim_{n\to\infty} \frac{\left(1 + \frac{3}{n}\right)^{n^2}}{\left(1 + \frac{3}{n+1}\right)^{n^2}}$$
▶ Подробное решение №8 (объединение под одну степень $n^2$)
Важно: Нельзя переходить к пределу по частям в числителе и знаменателе (там $(e^3)^n / (e^3)^n = \infty/\infty$)! Объединим дробь под общий показатель степени $n^2$:
$$\frac{1 + \frac{3}{n}}{1 + \frac{3}{n+1}} = \frac{\frac{n+3}{n}}{\frac{n+4}{n+1}} = \frac{(n+3)(n+1)}{n(n+4)} = \frac{n^2 + 4n + 3}{n^2 + 4n} = 1 + \frac{3}{n^2 + 4n}$$
Теперь возводим в степень $n^2$ и применяем второй замечательный предел: $$\lim_{n\to\infty} \left(1 + \frac{3}{n^2 + 4n}\right)^{n^2} = \lim_{n\to\infty} \left[\left(1 + \frac{3}{n^2 + 4n}\right)^{\frac{n^2+4n}{3}}\right]^{\frac{3n^2}{n^2+4n}} = e^{\lim_{n\to\infty} \frac{3n^2}{n^2+4n}} = \mathbf{e^3}$$
Ответ: $e^3$.
