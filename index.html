10. Число e

Последовательность: xₙ = (1 + 1/n)ⁿ возрастает и ограничена сверху (2 ≤ xₙ < 3)[span_76](start_span)[span_76](end_span).

Док-во огр. сверху: По биному Ньютона xₙ = 1 + 1 + ∑ₖ₌₂ⁿ [n(n-1)...(n-k+1) / (k! nᵏ)] ≤ 1 + 1 + ∑ₖ₌₂ⁿ (1/k!) ≤ 2 + ∑ₖ₌₂ⁿ 1/((k-1)k) = 2 + (1 - 1/2) + ... + (1/(n-1) - 1/n) = 3 - 1/n < 3[span_77](start_span)[span_77](end_span).

Возрастание: xₙ₊₁ / xₙ = ((n+2)/(n+1)) · (1 - 1/(n+1)²)ⁿ ≥ (по Бернулли) ((n+2)/(n+1)) · (1 - n/(n+1)²) = (n³ + 3n² + 3n + 2) / (n³ + 3n² + 3n + 1) > 1[span_78](start_span)[span_78](end_span).

По т. Вейерштрасса предел существует и обозначается e[span_79](start_span)[span_79](end_span).

18. Пределы на бесконечности и второй замечательный

Предел при x → +∞: limₓ→₊∞ f(x) = a ⇔ ∀ε > 0 ∃M > 0 ∀x > M: |f(x) - a| < ε (аналогично для -∞ и ∞).

Бесконечный предел: limₓ→ₓ₀ f(x) = ∞ ⇔ ∀M > 0 ∃δ > 0 ∀x (0 < |x - x₀| < δ ⇒ |f(x)| > M).

Второй замечательный предел: limₓ→∞ (1 + 1/x)ˣ = e.

Док-во (для x → +∞): Обозначим n = [x] (целая часть), n ≤ x < n + 1. При x ≥ 1:

(1 + 1/(n+1))ⁿ < (1 + 1/x)ˣ < (1 + 1/n)ⁿ⁺¹

Левая часть: (1 + 1/(n+1))ⁿ⁺¹ / (1 + 1/(n+1)) → e / 1 = e. Правая часть: (1 + 1/n)ⁿ · (1 + 1/n) → e · 1 = e. По т. о двух милиционерах предел равен e. Для x → -∞ сводится заменой t = -(x + 1) → +∞.
